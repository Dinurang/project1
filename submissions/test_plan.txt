In a Spring Boot application, an incoming HTTP request passes through four distinct layers before any data 
reaches MySQL. Testing REST Controllers, CORS, Authentication, and End-to-End API (spring-db) separately 
ensures each layer is verified in isolation rather than bundled into one opaque test:


Browser (localhost:4200)
   │
   ▼
[1. CORS Filter]            ──► Checks Origin, HTTP Method, and Allowed Headers
   │
   ▼
[2. Security / JWT Filter]  ──► Validates Bearer Token & Role (ADMIN vs. AGENT)
   │
   ▼
[3. REST Controller]        ──► Parses JSON/Params, calls Service, formats HTTP Status
   │
   ▼
[4. Full API + MySQL]       ──► Executes the entire stack together against real DB tables
